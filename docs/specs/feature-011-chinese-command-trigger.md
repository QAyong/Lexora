# Spec-011：中文输入法下触发命令菜单

**状态：** 已实现

## 1. 背景与目标

AI 输入框原先只识别 `/` 来打开命令建议。中文用户通常需要切换到英文输入状态才能输入 `/`，增加了操作成本。

现在支持在输入框开头使用中文顿号 `、` 触发同一组命令建议；原有 `/` 行为保持不变。

## 2. 行为约定

- 在输入框开头（允许前置空格）输入 `、`，后续输入命令前缀时显示命令建议，例如 `、rev` 可匹配 `/review`。
- `、` 仅作为命令菜单触发符，不改变命令本身的名称和执行格式。
- 选择命令后，触发符和已输入前缀由命令节点替换，不会残留在输入内容中；命令仍以原有 `/command` 格式保存和执行。
- `/`、`@`、`$` 的现有行为不变；在普通文本中间输入 `、` 不会作为命令触发符。

## 3. 实现

- `apps/buddy/src/modules/prompt-input/model/chatComposerInput.ts`：将 `、` 作为 slash-command trigger 识别，并沿用 `/` 的位置限制和建议筛选。
- `apps/buddy/src/modules/tasks/widgets/composer/__tests__/chatComposerEditing.spec.ts`：覆盖通过 `、` 打开命令建议，以及选择命令后触发符被正常替换。

复用现有命令建议与选择流程，无需调整命令数据、输入框 UI 或命令执行协议。
