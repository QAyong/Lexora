# Spec-006：空间侧栏与底部功能入口

**日期：** 2026-09-28  
**状态：** 草案（供审阅；仅描述设计，尚未实现）  
**设计基线：** 分支 `codex/fixed-primary-nav-rail`，基于提交 `73496281`

## 1. 目标

将当前独立的「任务 / 自动化 / 插件 / 设置」主导航侧栏移除，采用参考图中的空间侧栏布局。自动化、插件、设置和通知作为空间侧栏底部的一排直接入口；头像不显示在侧栏中，移至设置页面。

## 2. 界面结构

## 3. 行为

### 空间侧栏
- 左侧保留一条空间侧栏，主体按「置顶、会话、项目」组织。
- 项目可以展开或收起；展开后展示近期会话，并提供「加载更多」入口。
- 删除原本单独显示「任务、自动化、插件、设置」的主导航侧栏。
- 顶部隐藏按钮保留，只负责显示或隐藏空间侧栏，不负责切换底部功能入口。

### 底部功能入口
- 在空间侧栏底部固定排列四个可直接点击的图标入口，顺序参考图片：设置、插件、自动化、通知。
- 点击图标直接进入对应功能，不通过头像弹出菜单。
- 图标使用现有图标与主题样式；悬停时可显示功能名称，当前页面保持选中态。

### 头像与个人资料
- 头像不放在空间侧栏底部，也不作为功能菜单触发器。
- 头像和个人资料入口放在设置页面中。

## 4. 视觉约束

- 以参考图的紧凑侧栏和分组列表为方向，不额外增加装饰、卡片层级或新的配色体系。
- 继续使用产品现有主题颜色、图标、分隔线和交互状态；不在本方案中指定新的颜色值。
- 空间侧栏宽度沿用现有布局体系，具体尺寸在预览中确认，不预先增加额外尺寸规则。

## 5. 验收标准

- [ ] 原「任务 / 自动化 / 插件 / 设置」独立主导航侧栏已移除。
- [ ] 左侧空间侧栏显示置顶、会话、项目分组；项目可展开、收起。
- [ ] 项目展开后可看到近期会话，并能访问「加载更多」。
- [ ] 空间侧栏底部按参考顺序显示设置、插件、自动化、通知四个直接入口。
- [ ] 点击底部图标直接进入对应功能，不弹出头像菜单。
- [ ] 顶部隐藏按钮只控制空间侧栏。
- [ ] 头像和个人资料入口位于设置页面，不显示在侧栏中。
- [ ] 界面继续使用现有主题与图标样式，不引入额外装饰或独立色板。

## 6. 未决事项

- 「加载更多」每次加载数量和具体触发方式沿用现有会话列表规则，若现有规则不适用，再单独确认。
