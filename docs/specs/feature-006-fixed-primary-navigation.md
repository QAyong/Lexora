# Spec-006：合并侧栏与底部功能入口

**日期：** 2026-09-28  
**状态：** 草案（已按反馈修订；仅描述设计，尚未实现）  
**设计基线：** 分支 `codex/feature-006-fixed-primary-navigation`，基于提交 `73496281`

## 1. 目标

当前桌面端左侧存在两根并排竖栏：全局常驻的「任务 / 自动化 / 插件 / 设置」主导航侧栏，以及只在任务页显示的空间侧栏。本方案把两者**合并为一根侧栏**：

- 删除独立的主导航侧栏，其底部功能入口并入空间侧栏底部。
- 空间侧栏自身的「置顶 / 空间 / 任务」结构与交互**保持现状不变**，本方案不新增分组、不改动分组命名。
- 自动化、插件、设置、通知作为空间侧栏底部的一排直接入口。
- 头像不显示在侧栏中，移至设置页面。
- 非任务页面（自动化、插件、设置）在左下角提供「返回」入口。

## 2. 界面结构

任务页（合并后只剩一根侧栏）：

```text
┌──────────────────┬─────────────────────────────────┐
│ 顶栏控制区        │ 顶栏 / 页面操作区                │
├──────────────────┼─────────────────────────────────┤
│ 置顶              │                                 │
│                  │                                 │
│ 空间              │            主内容区              │
│  ▾ 空间 A         │                                 │
│    · 任务一       │                                 │
│    · 任务二       │                                 │
│  ▸ 空间 B         │                                 │
│                  │                                 │
│ 任务              │                                 │
│  · 任务           │                                 │
├──────────────────┤                                 │
│ ⚙ 设置 🔌 插件 ◷ 自动化 ♧ 通知 │                  │
└──────────────────┴─────────────────────────────────┘
```

非任务页面（自动化 / 插件 / 设置）：

```text
┌──────────────────┬─────────────────────────────────┐
│                  │ 顶栏 / 页面操作区                │
│                  │                                 │
│                  │            页面内容              │
│                  │                                 │
│ ← 返回            │                                 │
└──────────────────┴─────────────────────────────────┘
```

## 3. 行为

### 侧栏合并

- 删除原「任务 / 自动化 / 插件 / 设置」主导航侧栏。
- 空间侧栏保留现有内容与交互：置顶、空间、任务三段；空间可展开、收起并展示其下任务；置顶支持拖拽排序。
- 空间侧栏同时承载底部功能入口，成为桌面端唯一的左侧竖栏。

### 底部功能入口

- 在空间侧栏底部固定排列四个可直接点击的图标入口，顺序为：设置、插件、自动化、通知。
- 点击图标直接进入对应功能，不通过头像弹出菜单。
- 通知入口保留未读数徽标与现有通知面板交互。
- 图标使用现有图标与主题样式；悬停时可显示功能名称，当前页面保持选中态。

### 非任务页面

- 自动化、插件、设置页面在左下角提供「返回」入口，用于回到任务页。
- 这些页面不再依赖主导航侧栏完成模块间跳转。

### 头像与个人资料

- 头像不放在空间侧栏底部，也不作为功能菜单触发器。
- 头像和个人资料入口放在设置页面。

### 顶部隐藏按钮

- 顶部隐藏按钮保留，只负责显示或隐藏合并后的空间侧栏，不负责切换底部功能入口。

## 4. 视觉约束

- 以参考图的紧凑侧栏为方向，不额外增加装饰、卡片层级或新的配色体系。
- 继续使用产品现有主题颜色、图标、分隔线和交互状态；不在本方案中指定新的颜色值。
- 空间侧栏宽度沿用现有布局体系，具体尺寸在预览中确认，不预先增加额外尺寸规则。
- 底部四个图标入口的尺寸、间距与悬停/选中态复用现有图标按钮样式。

## 5. 验收标准

- [ ] 原「任务 / 自动化 / 插件 / 设置」独立主导航侧栏已移除。
- [ ] 任务页左侧只剩一根侧栏，且保留置顶、空间、任务三段结构与空间展开/收起能力。
- [ ] 空间侧栏底部按参考顺序显示设置、插件、自动化、通知四个直接入口。
- [ ] 点击底部图标直接进入对应功能，不弹出头像菜单；通知入口保留未读徽标。
- [ ] 自动化、插件、设置页面左下角有「返回」入口，可回到任务页。
- [ ] 顶部隐藏按钮只控制合并后的空间侧栏。
- [ ] 头像和个人资料入口位于设置页面，不显示在侧栏中。
- [ ] 界面继续使用现有主题与图标样式，不引入额外装饰或独立色板。

## 6. 未决事项

- **加载更多：** 本次不实现。现有任务列表为一次性加载，没有可分页规则可沿用。
- **头像归属：** 设置页中头像与个人资料入口的具体分类待确认。
- **「返回」形态：** 图标按钮或文字按钮、是否显示目标页面名称，在预览中确认。
